Функции:
- build_transition_matrix(p_one, rho) -> строит матрицу вероятностей переходов 2x2.
- generate_chain(length, p_one, matrix, seed) -> генерирует массив из 0 и 1 заданной длины.

Переменные:
- p_one : базовая вероятность появления 1 (доля единиц).
- rho : коэффициент корреляции / "залипания" одинаковых символов подряд.
- p00, p01, p10, p11 : вероятности переходов (0->0, 0->1, 1->0, 1->1).
- matrix : таблица 2x2 с вероятностями переходов.
- length : длина генерируемой цепочки.
- seed : зерно генератора случайных чисел (для повторяемости).
- rng : объект генератора случайных чисел.
- chain : итоговый массив из 0 и 1.
- rand_vals : массив случайных чисел от 0 до 1 для выбора символов.
- prev_symbol : предыдущий элемент в цепочке (0 или 1).
- prob_of_one : вероятность поставить 1 на текущем шаге.


Функции:
- count_pairs(chain) -> считает количество соседних пар (n00, n01, n10, n11).
- norm_cdf(x) -> функция стандартного нормального распределения (для стат. тестов).
- sample_correlation(chain) -> вычисляет реальный коэффициент корреляции (оценка rho).
- estimate_joint_probs(chain) -> считает долю каждой пары от общего числа пар.
- estimate_conditional_probs(chain) -> оценивает вероятности переходов в единицу (p01_hat, p11_hat).

Переменные:
- curr_s, next_s : сдвинутые срезы цепочки (текущий и следующий элементы).
- n00, n01, n10, n11 : количество встреченных пар (00, 01, 10, 11).
- denom : знаменатель в формуле корреляции (проверка деления на ноль).
- r : выборочный коэффициент корреляции.
- n_pairs : общее количество соседних пар (длина цепочки минус 1).
- n0, n1 : сколько раз встретились 0 и 1 (не считая последний символ).
- p01_hat, p11_hat : восстановленные по данным вероятности переходов 0->1 и 1->1.


1. Вероятности переходов (p = p_one):
p01 = p * (1 - rho)
p11 = p + (1 - p) * rho
p00 = 1 - p01
p10 = 1 - p11

2. Выборочный коэффициент корреляции (оценка rho):
r = (n11 * n00 - n10 * n01) / sqrt((n11 + n10) * (n11 + n01) * (n01 + n00) * (n10 + n00))

3. Совместные вероятности пар (n_pairs = длина - 1):
P(00) = n00 / n_pairs
P(01) = n01 / n_pairs
P(10) = n10 / n_pairs
P(11) = n11 / n_pairs

4. Оценка условных вероятностей (восстановление матрицы):
p01_hat = n01 / (n00 + n01)
p11_hat = n11 / (n10 + n11)

5. Функция нормального распределения:
F(x) = 0.5 * (1 + erf(x / sqrt(2)))
